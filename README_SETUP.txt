DOCTOR BOOKING PROJECT SETUP

1. Install XAMPP or MySQL Server
2. Create database using:
   database/doctor_booking.sql

3. MySQL Credentials:
   username = root
   password = 1234

4. Add mysql-connector-j jar inside:
   WEB-INF/lib/

5. Deploy project on Apache Tomcat 9+

6. Open browser:
   http://localhost:8080/doctor-booking/

Booking form is connected with MySQL database.
